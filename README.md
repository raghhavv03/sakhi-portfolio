# Sakhi Rana — portfolio

Personal portfolio site for a UI/UX & product designer. Built with React,
Vite, Tailwind, and Framer Motion. Static — no backend.

## Quick start

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run lint
npm run preview  # production build on :4173
```

Asset pipelines (optional):

```bash
npm run optimize:scene   # hero scenes → public AVIF/WebP
npm run optimize:about   # About photos → public/images/about
```
